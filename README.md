## 先搞清楚：IPLC 到底是什么

IPLC 本质上是一条点对点的跨境专用线路。你的流量从入口机房进去，通过专线直达出口节点，中间不走公网。这带来两个直接结果：

- **延迟低且稳定**。因为不绕公网，端内延迟基本是固定值。比如沪港线路端内延迟约 21ms，沪日约 25~28ms，这个数字不会因为晚上八点大家都在上网而变差。
- **独享资源**。正规 IPLC 服务商会给你独享的独立 IPv4，不存在和几百人共用一个出口 IP 被牵连的问题。

这也是它和普通机场的根本区别。机场本质是“多人共享的中转服务”，优点是便宜、节点多，缺点是高峰期质量不可控；IPLC 是“你自己的一条线”，优点是稳定、独享、延迟可预期，缺点是贵，而且通常只覆盖固定的几条线路。

顺带一提 IEPL 和 IPLC 的关系：两者都是点对点专线，IEPL 是以太网层的二层专线，IPLC 更接近传统定义的专线组网。对使用者来说，实际体验差异远小于价格差异，选的时候不用太纠结名词，重点看具体线路的延迟、带宽和计费方式。

## 判断“IPLC 哪家好”的五个硬指标

与其背品牌名，不如拿这几个指标去套每一家：

1. **端内延迟是否公开、具体**。敢写“21ms”“25~28ms”这种精确数字的服务商，通常对自家线路质量心里有数。只写“低延迟”“高速”不给数字的，警惕。
2. **入口线路是否可选**。入口决定你从本地到入口机房的这段质量。好的服务商会提供 BGP 多线、电信、移动、联通等多种入口可选，让不同运营商的用户都能就近接入。
3. **独享 IPv4**。这是专线的基本盘，没有独享 IP 的所谓“专线”要打个问号。
4. **计费方式**。流量计费适合用量波动大的场景，独享带宽计费适合长期稳定跑满的场景。两种都支持的商家，灵活性更高。
5. **售后和限制条款**。能不能退款、退款条件是什么、有没有地域限制，这些直接写在 FAQ 里的条款，比宣传页上的“7×24 服务”更值得细看。
